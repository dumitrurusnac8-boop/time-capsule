# Капсула времени

Одна страница: видеопослание, таймеры до открытия и зашифрованное хранилище с письмом,
фотографиями и видео. Хостинг бесплатный (GitHub Pages), пароль от хранилища живёт
в бумажном конверте.

Даты по умолчанию: запечатана 19 сентября 2026, открывается 19 сентября 2036.

## Что нужно один раз

Node 22 уже стоит. В папке проекта:

```powershell
npm install
npm test
```

`npm test` проверяет арифметику таймеров и то, что хранилище, запечатанное здесь,
открывается тем же кодом, что работает в браузере. Ожидание: `13 passed, 0 failed`.

## Порядок сборки

1. **Настройки.** Открой `docs/config.js`: имя друга в родительном падеже
   (`friendName: "Саши"`), даты, форма кадра видео.

2. **Видео.** Запиши послание на телефон, скинь файл в папку проекта и сожми:

   ```powershell
   npm run video -- C:\путь\к\послание.mov
   ```

   Получится `docs/video.mp4` и обложка `docs/poster.jpg`. Скрипт печатает размер
   и форму кадра, впиши её в `videoAspect`. Файл больше 100 MiB GitHub не примет,
   от 50 MiB предупредит. Если много, повтори с `--crf 27`.

3. **Хранилище.** Сделай папку `vault-src` и положи туда:
   письмо файлом `.txt` (можно несколько), фото `.jpg`/`.png`, видео `.mp4`.
   HEIC с айфона браузер не покажет, сохрани фото как JPG. Видео `.mov` прогони
   через `npm run video -- файл.mov --out vault-src\ролик.mp4`.

   ```powershell
   npm run seal -- vault-src
   ```

   Скрипт зашифрует всё в `docs/vault/`, расшифрует обратно и сверит байт в байт,
   потом напечатает пароль **один раз**. Запиши его на бумагу сразу.
   Перезапуск создаёт новый пароль и новое хранилище.

4. **Посмотреть глазами.**

   ```powershell
   npm run serve
   ```

   Открой http://localhost:8765/ и http://localhost:8765/#open, введи пароль,
   убедись, что письмо, фото и видео открываются. `#open` показывает открытое
   состояние до срока, `#sealed` прячет его после срока.

5. **Выложить.**

   ```powershell
   .\deploy.ps1
   ```

   Создаст публичный репозиторий `time-capsule`, включит Pages и напечатает адрес.
   Первая сборка 1-3 минуты. Репозиторий публичный, потому что Pages для приватных
   репозиториев платные; файлы хранилища видны всем, но зашифрованы.

6. **QR-код.** Только после того, как адрес открылся в браузере:

   ```powershell
   npm run qr -- https://ИМЯ.github.io/time-capsule/
   ```

   Файлы `out/qr.svg` и `out/qr.png`. Отсканируй PNG телефоном до печати.

7. **Конверт.** Внутрь: пароль на бумаге, флешка с папкой `vault-src` как есть и
   адрес страницы. Это страховка на случай, если за десять лет пропадёт GitHub,
   аккаунт или бумажка с адресом. Себе поставь напоминание на 19 сентября 2036.

## Как устроено

- `docs/` публикуется как сайт. `index.html`, `style.css`, `capsule.js`, `config.js`.
- `docs/vault/`: `vault.json` (соль и число итераций), `manifest.bin` (список
  файлов, зашифрован), `fNNN.bin` (сами файлы, каждый зашифрован отдельно).
  Ключ: PBKDF2-SHA256, 600 000 итераций, AES-256-GCM. Расшифровка идёт в браузере,
  ничего никуда не отправляется.
- Таймеры считают в местном времени того, кто смотрит. Форма хранилища открывается
  в полночь 19 сентября 2036 по его часам.
- `tools/`: `seal_vault.js`, `compress_video.js` (ffmpeg внутри npm-пакета),
  `make_qr.js`, `test_capsule.js`, `make_sample.js` (образец содержимого),
  `screenshots.py` (нужен Playwright, только для проверки).
